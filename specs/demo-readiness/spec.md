# Feature — Demo readiness

Prepare a portable set of approximately 48 to 60 photos with matching manifest notes. The set covers all three destinations, several urgency levels, a same-photo pair with different notes, and a result suitable for showing threshold replay. Select the pair and replay case using results observed during rehearsal.

The presenter runbook covers local startup, Foundry configuration, the raw HTTP example, the single-package walkthrough, the live batch, the detail panel, and threshold replay. One talk slide compares the Azure OpenAI Decisions endpoint and GPT-6 Luna to the System One setup used in the demo.

Rehearse on the chosen deployment and presentation display. Record the batch size, in-flight limit, measured throughput and latency, and any rate limits or failures. Use the successful rehearsal to set the stage batch and concurrency.
